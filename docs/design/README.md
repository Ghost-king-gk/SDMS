# Word 设计文档

此目录用于存放每位成员的 Word 设计文档。每份文档应：

- 明确成员姓名、学号、分工和本人完成的章节/功能；
- 说明需求分析、总体设计、界面设计、数据组织、异常处理和测试；
- 包含流程图、示意图、统计图表、运行或测试截图；
- 正文不少于 20 页，附录不计入页数；
- 遵循教师规定的文件命名格式。

# 需求基线

本文件是对 [`Requests/`](../Requests/) 原始材料的项目侧整理，不替代原始需求。原始 Markdown 与 PDF 保留不变，需求发生变化时应先更新讨论记录，再同步本文件。

## 目标

使用 Python 设计一个简易的图形化日程管理系统，帮助用户安排和管理日程。

## 功能需求

| 编号 | 需求 | 验收方向 |
| --- | --- | --- |
| F-01 | 图形用户界面 | 有日程列表、日期/日历选择和主要功能按钮 |
| F-02 | 添加日程 | 可录入标题、日期、时间、备注并保存 |
| F-03 | 查看日程 | 按选择日期展示当天全部日程 |
| F-04 | 修改日程 | 可选中记录并修改其信息 |
| F-05 | 删除日程 | 可选中记录并安全、准确地删除 |
| F-06 | 错误处理 | 非法输入或异常操作有友好提示 |

## 非功能与实现提示

- 使用 Python 实现，不改变题目范围。
- GUI 可在实现阶段选择 Tkinter 或 PyQt，并记录技术选型理由。
- 使用 `datetime` 处理日期和时间，保证比较、显示和输入校验一致。
- 界面应简洁清晰，操作结果应容易理解。
- 可使用列表、字典或后续确定的持久化方式组织日程数据。

## 交付要求

- 每位成员一份 Word 设计文档，正文不少于 20 页（附录不计入），清楚说明成员分工并包含流程图、示意图、统计图表和测试截图。
- 每组一份不少于 20 页的 PowerPoint，包含图表和实现方法；首页列出按贡献大小排序的姓名与学号，页内标注具体贡献。
- 源代码位于 `src/`；如使用第三方包并按作业要求随源代码提交，放入 `src/lib/`。
- README 说明环境配置、编译/检查、运行、测试和结果。
